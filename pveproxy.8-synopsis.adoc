*pveproxy* `<COMMAND> [ARGS] [OPTIONS]`

*pveproxy help* `[OPTIONS]`

获取指定命令的帮助。

`--extra-args` `<array>` ::

显示特定命令的帮助

`--verbose` `<boolean>` ::

详细输出格式。

*pveproxy restart*

重启守护进程（如果未运行则启动）。

*pveproxy start* `[OPTIONS]`

启动守护进程。

`--debug` `<boolean>` ('default =' `0`)::

调试模式 - 保持在前台运行

*pveproxy status*

获取守护进程状态。

*pveproxy stop*

停止守护进程。

常用命令示例：

----
pveproxy status
pveproxy restart
----
