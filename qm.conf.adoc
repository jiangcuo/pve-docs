`/etc/pve/qemu-server/<VMID>.conf` 文件用于存储虚拟机配置，其中 "VMID" 是指定虚拟机的数字 ID。

NOTE: ID < 100 保留供内部用途使用。


== 文件格式

该文件使用简单的冒号分隔键/值格式。每行采用以下格式：

 OPTION: value

文件中的空行会被忽略，以 `#` 字符开头的行会作为注释处理，也会被忽略。

可以使用 `qm` 命令生成和修改这些文件。

=== 常用命令示例

查看指定虚拟机的当前配置：

----
qm config <VMID>
----

验证并查看 `qm` 命令的可用子命令：

----
qm help
----
