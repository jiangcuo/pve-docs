ifndef::manvolnum[]
= pvestatd - Proxmox VE 状态守护进程
endif::manvolnum[]

该守护进程会定期查询虚拟机、存储和容器的状态。查询结果会发送到集群中的所有节点。

== 常用命令示例

----
systemctl status pvestatd.service
journalctl -u pvestatd.service
----
