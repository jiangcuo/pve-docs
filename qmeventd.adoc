ifndef::manvolnum[]
= PVE QEMU 事件守护进程
:pve-toplevel:
endif::manvolnum[]

`qmeventd` 是一个守护进程，它在 PATH 上监听来自 QEMU QMP 套接字的传入连接，
并等待 `SHUTDOWN` 事件。随后当客户端断开连接时，它会执行
`/usr/sbin/qm cleanup`。这样可以方便地清理残留的 tap 设备、vGPU 等资源。
