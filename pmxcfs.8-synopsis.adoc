*pmxcfs* `[OPTIONS]`

帮助选项：

`-h`, `--help`:: 显示帮助选项

应用选项：

`-d`, `--debug`:: 打开调试消息

`-f`, `--foreground`:: 不将服务器守护进程化

`-l`, `--local`:: 强制本地模式（忽略 corosync.conf，强制 quorum）

该服务通常使用 systemd 工具集启动和管理。服务名为 'pve-cluster'。

.常用命令示例

 systemctl start pve-cluster

 systemctl stop pve-cluster

 systemctl status pve-cluster
