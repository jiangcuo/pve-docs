ifndef::manvolnum[]
= spiceproxy - SPICE 代理服务
endif::manvolnum[]

http://www.spice-space.org[SPICE]（Simple Protocol for Independent Computing
Environments）是一种开放的远程计算解决方案，可让客户端访问远程显示和设备
（例如键盘、鼠标、音频）。主要使用场景是远程访问虚拟机和容器。

该守护进程监听 TCP 端口 3128，并实现一个 HTTP 代理，用于将 SPICE 客户端发出的
'CONNECT' 请求转发到正确的 {pve} VM。它以用户 `www-data` 运行，并且权限非常
有限。


== 基于主机的访问控制

可以配置类似 "apache2" 的访问控制列表。其值从 `/etc/default/pveproxy` 文件读取。
详细信息请参阅 `pveproxy` 文档。

.常用命令示例
----
# spiceproxy status
# systemctl status spiceproxy.service
----
