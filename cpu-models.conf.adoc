= 自定义 CPU 型号配置

:pve-toplevel:
:title: Manual: cpu-models.conf
endif::wiki[]

`/etc/pve/virtual-guest/cpu-models.conf` 文件用于存储自定义 CPU 型号。
虚拟机可以使用这些型号来访问高级 CPU 功能（例如自定义 CPU 标志）。


== 文件格式

每个 CPU 型号在文件中都有自己的独立小节，并以下列标题开头：

 cpu-model: <name>

请注意，<name> 不包含 `custom-` 前缀；在虚拟机配置中表示自定义 CPU 型号时
才需要该前缀。

例如，如果 <name> 为 `foobar`，则虚拟机的 CPU 需要配置为 `custom-foobar`。

每个小节可以指定多个选项。选项行使用一个 TAB 字符或多个空格缩进。每个选项及其值
用一个空格分隔，例如：

 reported-model qemu64

所有可用选项见下文。

空行以及以 `#` 开头的行会被忽略。


== 选项

include::cpu-models.conf.5-opts.adoc[]


== 示例文件

----
cpu-model: avx
    flags +avx;+avx2
    phys-bits host
    hidden 0
    hv-vendor-id proxmox
    reported-model kvm64
----
