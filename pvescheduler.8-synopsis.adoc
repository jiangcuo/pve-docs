*pvescheduler* `<COMMAND> [ARGS] [OPTIONS]`

*pvescheduler help* `[OPTIONS]`

获取指定命令的帮助信息。

`--extra-args` `<array>` ::

显示特定命令的帮助信息

`--verbose` `<boolean>` ::

详细输出格式。

*pvescheduler restart*

重启守护进程（如果尚未运行则启动）。

*pvescheduler start* `[OPTIONS]`

启动守护进程。

`--debug` `<boolean>` ('default =' `0`)::

调试模式 - 保持在前台运行

*pvescheduler status*

获取守护进程状态。

*pvescheduler stop*

停止守护进程。

=== 常用命令示例

查看 `pvescheduler` 状态：

----
# pvescheduler status
----
