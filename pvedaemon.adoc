ifndef::manvolnum[]
= pvedaemon - Proxmox VE API 守护进程
endif::manvolnum[]

该守护进程在 `127.0.0.1:85` 上公开完整的 {pve} API。它以 `root` 身份运行，
并有权限执行所有特权操作。

NOTE: 该守护进程仅监听本地地址，因此无法从外部访问。`pveproxy` 守护进程负责向外部
公开 API。
