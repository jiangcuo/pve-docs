== 改进 {pve} 文档
ifdef::wiki[]
:pve-toplevel:
endif::wiki[]

始终欢迎对 {pve} 文档进行贡献和改进。可以通过多种方式参与贡献。

如果你在本文档中发现错误或其他可改进之处，请在
https://bugzilla.proxmox.com/[Proxmox 缺陷跟踪器] 提交 bug，以提出修正建议。

如果要提出新的内容，请选择以下选项之一：

* Wiki：对于特定部署、操作指南或教程，wiki 是合适的贡献位置。

* 参考文档：对于对所有用户都有帮助的通用内容，请向参考文档提交贡献建议。
  这包括有关安装、配置、使用和排查 {pve} 功能问题的所有信息。参考文档使用
  https://en.wikipedia.org/wiki/AsciiDoc[AsciiDoc 格式] 编写。要编辑该文档，
  需要克隆位于 `git://git.proxmox.com/git/pve-docs.git` 的 git 仓库，
  然后按照
  https://git.proxmox.com/?p=pve-docs.git;a=blob_plain;f=README.adoc;hb=HEAD[README.adoc]
  文档操作。

NOTE: 如果你有兴趣参与 {pve} 代码库开发，
{webwiki-url}Developer_Documentation[开发者文档] wiki 文章会说明从何处开始。
