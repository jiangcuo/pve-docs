ifndef::manvolnum[]
= 还原虚拟机
endif::manvolnum[]


将 QemuServer vzdump 备份 `archive` 还原到虚拟机 `vmid`。如果未指定 `storage`，卷会分配到原始存储上。

=== 常用命令示例

查看 `qmrestore` 可用参数：

----
qmrestore help
----

将备份归档还原为指定 VMID 的虚拟机：

----
qmrestore /var/lib/vz/dump/vzdump-qemu-100.vma.zst 101 --storage local-lvm
----
