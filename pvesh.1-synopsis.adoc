*pvesh* `<COMMAND> [ARGS] [OPTIONS]`

*pvesh create* `<api_path>` `[OPTIONS]` `[FORMAT_OPTIONS]`

对 <api_path> 调用 API POST。

`<api_path>`: `<string>` ::

API 路径。

`--noproxy` `<boolean>` ::

禁用自动代理。

*pvesh delete* `<api_path>` `[OPTIONS]` `[FORMAT_OPTIONS]`

对 <api_path> 调用 API DELETE。

`<api_path>`: `<string>` ::

API 路径。

`--noproxy` `<boolean>` ::

禁用自动代理。

*pvesh get* `<api_path>` `[OPTIONS]` `[FORMAT_OPTIONS]`

对 <api_path> 调用 API GET。

`<api_path>`: `<string>` ::

API 路径。

`--noproxy` `<boolean>` ::

禁用自动代理。

*pvesh help* `[OPTIONS]`

获取指定命令的帮助。

`--extra-args` `<array>` ::

显示特定命令的帮助。

`--verbose` `<boolean>` ::

详细输出格式。

*pvesh ls* `<api_path>` `[OPTIONS]` `[FORMAT_OPTIONS]`

列出 <api_path> 下的子对象。

`<api_path>`: `<string>` ::

API 路径。

`--noproxy` `<boolean>` ::

禁用自动代理。

*pvesh set* `<api_path>` `[OPTIONS]` `[FORMAT_OPTIONS]`

对 <api_path> 调用 API PUT。

`<api_path>`: `<string>` ::

API 路径。

`--noproxy` `<boolean>` ::

禁用自动代理。

*pvesh usage* `<api_path>` `[OPTIONS]`

打印 <api_path> 的 API 用法信息。

`<api_path>`: `<string>` ::

API 路径。

`--command` `<create | delete | get | set>` ::

API 命令。

`--returns` `<boolean>` ::

包含返回数据的 schema。

`--verbose` `<boolean>` ::

详细输出格式。

.常用命令示例

----
pvesh get /nodes
pvesh get /nodes/<node>/status
pvesh ls /nodes/<node>
----
