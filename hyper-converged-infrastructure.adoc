== 超融合基础设施

ifdef::wiki[]
:pve-toplevel:
endif::wiki[]

{pve} 是一个虚拟化平台，紧密集成计算、存储和网络资源，并管理高可用集群、
备份/还原以及灾难恢复。所有组件均为软件定义，并彼此兼容。

因此，可以通过集中式 Web 管理界面像管理单一系统一样管理这些组件。这些能力使
{pve} 成为部署和管理开源
https://en.wikipedia.org/wiki/Hyper-converged_infrastructure[hyper-converged infrastructure]
的理想选择。

=== 使用 {pve} 构建超融合基础设施（HCI）的优势

超融合基础设施（HCI）尤其适用于基础设施需求较高但管理预算有限的部署场景，
也适用于远程和分支机构环境等分布式部署，或虚拟私有云和公有云场景。

HCI 提供以下优势：

- 可扩展性：可以无缝扩展计算、网络和存储设备（即快速且相互独立地扩展
  服务器和存储）。

- 低成本：{pve} 是开源软件，并集成计算、存储、网络、备份和管理中心等所需
  组件。它可以替代昂贵的计算/存储基础设施。

- 数据保护和效率：集成了备份和灾难恢复等服务。

- 简洁性：配置简单，并支持集中式管理。

- 开源：无厂商锁定。


=== 超融合基础设施：存储

{pve} 对部署超融合存储基础设施提供了紧密集成的支持。例如，可以仅通过 Web
界面部署并管理以下两种存储技术：

- *Ceph*：一种具备自修复和自管理能力的共享、可靠且高度可扩展的存储系统。
  请参见 xref:chapter_pveceph[如何在 {pve} 节点上管理 Ceph 服务]

- *ZFS*：结合文件系统和逻辑卷管理器，提供广泛的数据损坏防护、多种 RAID
  模式、快速且成本低的快照等功能。请参见
  xref:chapter_zfs[如何在 {pve} 节点上发挥 ZFS 的能力]。

除上述技术外，{pve} 还支持集成多种其他存储技术。可以在
xref:chapter_storage[存储管理器章节]中了解相关内容。
