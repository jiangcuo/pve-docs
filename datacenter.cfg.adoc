文件 `/etc/pve/datacenter.cfg` 是 {pve} 的配置文件。它包含由所有节点使用的
集群范围默认值。

== 文件格式

该文件使用简单的冒号分隔键/值格式。每一行采用以下格式：

 OPTION: value

文件中的空行会被忽略，以 `#` 字符开头的行会被视为注释并同样被忽略。
