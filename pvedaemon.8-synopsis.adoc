*pvedaemon* `<COMMAND> [ARGS] [OPTIONS]`

*pvedaemon help* `[OPTIONS]`

获取指定命令的帮助。

`--extra-args` `<array>` ::

显示特定命令的帮助。

`--verbose` `<boolean>` ::

详细输出格式。

*pvedaemon restart*

重启守护进程；如果尚未运行，则启动它。

*pvedaemon start* `[OPTIONS]`

启动守护进程。

`--debug` `<boolean>` ('default =' `0`)::

调试模式，保持在前台运行

*pvedaemon status*

获取守护进程状态。

*pvedaemon stop*

停止守护进程。

.常用命令示例

----
pvedaemon status
systemctl status pvedaemon.service
----
