ifndef::manvolnum[]
= pvescheduler - Proxmox VE 调度器守护进程
endif::manvolnum[]

此守护进程负责按照计划启动作业，例如复制作业和 vzdump 作业。

对于 vzdump 作业，它会从 `/etc/pve/jobs.cfg` 文件读取配置。

== 常用命令示例

查看调度器服务状态和相关日志时，可使用标准 Debian 系统命令：

----
# systemctl status pvescheduler
# journalctl -u pvescheduler
----
