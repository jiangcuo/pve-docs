[[storage_iscsidirect]]
== 用户态 iSCSI 后端
ifdef::wiki[]
:pve-toplevel:
:title: Storage: User Mode iSCSI
endif::wiki[]

存储池类型：`iscsidirect`

该后端提供的功能基本与 Open-iSCSI 后端相同，但通过用户态库实现。要使用该后端，需要安装
`libiscsi` 软件包。

需要注意的是，该后端不涉及内核驱动，因此可视为一种性能优化方式。但它也有一个缺点：
不能在这类 iSCSI LUN 之上使用 LVM。因此，所有空间分配都需要在存储服务器端管理。

=== 配置

用户态 iSCSI 后端使用与 Open-iSCSI 后端相同的配置选项。

.配置示例（`/etc/pve/storage.cfg`）
----
iscsidirect: faststore
     portal 10.10.10.1
     target iqn.2006-01.openfiler.com:tsn.dcb5aaaddd
----

=== 存储特性

NOTE: 该后端仅适用于虚拟机。容器不能使用此驱动。

.后端 `iscsidirect` 的存储特性
[width="100%",cols="m,m,3*d",options="header"]
|==============================================================================
|内容类型       |镜像格式       |共享   |快照      |克隆
|images         |raw            |是     |否        |否
|==============================================================================

=== 常用命令示例

查看当前存储状态：

----
# pvesm status
----

扫描可用 iSCSI target：

----
# pvesm scan iscsi <portal>
----
