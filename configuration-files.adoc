[[configuration_files]]
= 常规

{pve} 中的大多数配置文件都位于挂载在 `/etc/pve` 的
xref:chapter_pmxcfs[共享集群文件系统]上。也存在例外，例如用于备份的节点特定
配置文件 `/etc/vzdump.conf`。

通常，配置文件中的属性派生自相关 API 端点同样使用的 JSON Schema。

[[configuration_files_casing]]
== 属性名称的大小写形式

从历史上看，较长的属性（以及子属性）通常使用 `snake_case`，或者写成一个单词。
这很可能是因为 {pve} 技术栈主要使用 Perl 编程语言开发，在 Perl 中访问使用
`kebab-case` 的属性需要额外的引号；同时早期开发阶段样式约束较少，不同开发者
采用了不同约定。

对于新属性，首选 `kebab-case`。计划为现有 `snake_case` 属性引入别名，并在长期
方向上，在保持还原配置时向后兼容的同时，将 API、CLI 和正在使用的配置文件切换
为 `kebab-case`。
